# Prompt log

The team's real prompts to the model, in order, one file per phase.

Rules for this folder:

- Team prompts are verbatim. Long pasted course material is replaced by a marker saying what was omitted.
- Model responses are summaries, and they say so.
- Nothing is invented or tidied up after the fact. Mistakes stay in.
- No credentials, ID numbers or private details. Check before each commit, because this folder is public.
